# Web giới thiệu CES Anh – Trung – Kids

Trang mời trung tâm, trường học nhượng quyền và giáo viên đăng ký khóa đào tạo.

- Trang: https://ces-training.github.io/CESgioithieu.h-c.mot.lan.duoc.hai.ngon.ngu/
- Form đăng ký gửi vào Google Sheet "Đăng ký đối tác & giáo viên – web giới thiệu CES" (thư mục Drive "Dữ liệu web Anh - Trung"), qua Apps Script trong `apps-script/DangKy.gs`. Link Web App nằm ở hằng `FORM_API` trong `index.html`.
- Sửa Apps Script xong: Triển khai → Quản lý triển khai → sửa → Phiên bản mới (giữ nguyên link /exec).
- Tên các bé trong video là tên giả.
